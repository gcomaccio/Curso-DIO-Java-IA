No geral, os modelos de linguagem não possuem memória persistente entre interações, ou seja, ele não lembram do que foi dito em conversas passadas depois que a interação termina, no entanto, dentro de uma mesma interação, o modelo consegue manter o contexto do que foi dito por meio de uma janela de contexto, que é um limite de tokens que o modelo consegue processar silmutâneamente. Cada modelo possui uma janela de contexto diferente, quando o limite é atingido, os tokens mais antigos são descartados para darem lugar ao tokens mais recentes.
